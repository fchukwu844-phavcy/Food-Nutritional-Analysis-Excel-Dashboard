# Food-Nutritional-Analysis-Excel-Dashboard
Project Overview
This project analyzes a food nutrition dataset using Microsoft Excel. The goal was to explore calorie and protein values and create an interactive dashboard that provides useful insights.

Tools Used
-Microsoft Excel
-Data Cleaning 
-PivotTables
-PivotCharts
-Slicers
-Dashboard Designs

Key Analysis
-Identified the Top 10 foods with the highest caloric values.
-Calculated the average caloric value of foods.
-Identified foods with the highest proteins values.
-Created an interactive dashboard for data exploration.

Key Insights
-Average caloric value : 237.36 calories.
-High-calorie foods include: General Tso's chicken  and Burger King Whopper Meal.
-Seafood such as tuna and salmon appeared among the highest-protein foods.
